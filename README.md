# project-calculator

Prototyp konfigurátora nacenenia projektov. Všetko je zatiaľ čistý frontend
(súbory v `src/`), aby sa dal rýchlo iterovať dizajn a logika kalkulácie.

## Spustenie

Stačí otvoriť `src/index.html` v prehliadači.

## Čo je pripravené

- Konfigurovateľný katalóg položiek (`src/config.js`).
- Kalkulačný engine so škálovateľnými cenovými módmi (unit, tiered, volume).
- Moderný UI layout pripravený na napojenie na databázu.

## Ďalšie kroky

- Napojenie na databázu (Supabase, Firebase, ...).
- Ukladanie projektov + export do PDF.
- Administrácia konfigurácie priamo z UI.
